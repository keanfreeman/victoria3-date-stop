# Date Stop

A Victoria 3 mod: pick a date, and the game pauses when it arrives.

**[Subscribe on the Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3827384545)**

![Date Stop](mod/thumbnail.png)

## Usage

1. Click the clock button at the bottom-right of the date box (top-right of the screen).
2. Choose a date, either:
   - directly with the Year / Month / Day buttons, or
   - relative to today: set a number under **In**, then click **Days**, **Weeks**, **Months** or **Years**.
3. Optionally pick a **Reason** (44 presets, e.g. Election, Truce ends, Construction finishes) to remind yourself why you set it.
4. Optionally set **Repeat** to Weekly, Monthly or Yearly.
5. Click **Set**.

On that date the game pauses and shows a popup with your reason. A repeating stop then moves itself to the next date. **Clear** removes the stop and resets the reason and repeat. Changing the reason or repeat updates a stop that's already set; changing the date needs **Set** again.

Reasons are presets because mods can't save typed text in a save game.

The +/− buttons work like the game's own: click for 1, Shift-click for 5, Ctrl-click for 10.

## Compatibility

- Built for Victoria 3 1.13.
- Safe to add to an existing save.
- Replaces `gui/timemanip.gui`, so it conflicts with other mods that change the time controls.
- Text is English only. Other languages show the English text.

## Manual install

Copy the `mod/` folder to `Documents/Paradox Interactive/Victoria 3/mod/Date Stop`. On Linux that's `~/.local/share/Paradox Interactive/Victoria 3/mod/Date Stop`. Then enable it in the launcher. A symlink works in-game but not in the launcher.

## How it works

Game script can neither read the date as a number nor pause the game. The mod works around both:

- **Reading the date:** today's date is found with a chain of `game_date >=` checks. These are generated by `tools/gen_date_effects.py` into `mod/common/scripted_effects/dsm_generated_effects.txt`.
- **Daily check:** while a stop is set, a hidden event checks the date once a day. On the target date it sets a flag.
- **Pausing:** a GUI `state` with `trigger_when` watches that flag and calls `TimeKeeper.TogglePause`.
- **Reasons:** stored as a number and shown as text through customizable localization. The list lives in `tools/gen_reasons.py`, which generates the handlers, lookups, text and picker GUI.

## Development

- `mod/` is exactly what ships.
- `tools/install.sh` copies `mod/` into your local mod folder. Run it after each change.
- After editing the reason list, run `python3 tools/gen_reasons.py` then `python3 tools/build_gui.py`.
- Don't edit `mod/gui/timemanip.gui` by hand. It's the vanilla file plus the snippets in `tools/`, assembled by `python3 tools/build_gui.py`.
- After a game patch, copy the new vanilla `game/gui/timemanip.gui` over `tools/timemanip.vanilla.gui` and rebuild.
